# Siemens Data Science Master Virtual Internship

## 📌 Internship Overview

This repository contains the documentation and supporting materials for my **Siemens Data Science Master Virtual Internship**, completed under the **AICTE – EduSkills Virtual Internship Program** with support from **Siemens**.

The internship was conducted over **8 weeks from April 2026 to June 2026** as part of the **B.Tech. Computer Science and Engineering** program at **IILM University, Greater Noida**.

The primary focus of the internship was to develop practical knowledge of **Data Science and Machine Learning workflows** using the **RapidMiner platform**, covering data engineering, machine learning, data preparation, automation, model deployment, monitoring, and platform administration.

## 🏢 Internship Program

The internship was provided through the **AICTE – EduSkills Virtual Internship Program** in collaboration with **Siemens and EduSkills Academy**.

The program followed a structured week-wise curriculum consisting of:

* Conceptual learning
* Hands-on practical activities
* Data science exercises
* Assignments and project submissions
* Weekly assessments
* Final Credential Validation / Internship Grade Point Assessment

The internship was successfully completed with an **“Outstanding” grade**.
